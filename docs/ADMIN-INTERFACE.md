# Административный журнал

- **Статус:** первая реализация списка и карточки события.
- **Доступ:** только пользователи с правами администратора Bitrix.
- **Пункт меню:** «Журнал интеграций» в разделе «Сервисы» административной панели.
- **Страница:** `/bitrix/admin/cmi_integrationinspector_events.php`.
- **Регистрация меню:** штатный `admin/menu.php` модуля; отдельные пользовательские файлы меню сайта не изменяются.
- **Иконки:** собственные CSS-классы и SVG-изображения для пункта меню и заголовка страницы; стили устанавливаются в `/local/themes/.default/`.

## Возможности первой версии

- список событий с постраничным выводом (50 записей);
- фильтры по источнику, статусу, направлению, диапазону дат и Correlation ID;
- переход к карточке события;
- просмотр метаданных запроса/ответа, контекста, payload и стека ошибки, если эти данные были разрешены настройками и сохранены;
- чтение через то же соединение, которое выбрано для записи Inspector настройкой `connection_name`;
- экспорт текущей выборки в CSV с сохранением активных фильтров (не более 10 000 событий за один файл); UTF-8 BOM для корректного открытия в табличных редакторах;
- защита CSV-значений от выполнения формул табличными редакторами;
- экранирование всех значений при выводе.

## Настройки модуля

Страница настроек доступна из раздела «Сервисы» административной панели и через стандартную страницу Bitrix `/bitrix/admin/settings.php?mid=codematrix.integrationinspector`. Доступ разрешён администраторам.

Настраиваются:

- включение и отключение записи новых событий (`enabled`);
- срок хранения истории от 1 до 3650 дней (`retention_days`, по умолчанию 30); ежедневный агент удаляет просроченные события;
- имя уже существующего соединения Bitrix (`connection_name`); пустое значение использует стандартное соединение;
- разрешение на запись payload запросов и ответов (`payloads_enabled`, по умолчанию выключено);
- запись файла и строки возникновения ошибки (`error_location_enabled`, по умолчанию выключено).

Модуль не создаёт и не изменяет соединения, пользователей БД или учётные данные. Если указано имя несуществующего соединения, запись и чтение журнала завершатся ошибкой; автоматического переключения на стандартное соединение нет. После сохранения настроек кэш сервиса Inspector сбрасывается.

## Ограничения

Это первая версия интерфейса, а не завершённая административная подсистема. Права пока ограничены проверкой администратора; отдельные роли и ACL ещё не реализованы. Нет удаления событий, повторного запуска интеграций и фоновой обработки. Экспорт ограничен 10 000 строками; для больших архивов потребуется отдельный потоковый механизм. Даты показываются в UTC, как они хранятся в таблице. Поиск по тексту сообщения и операции пока не предусмотрен.

Диагностические данные могут содержать чувствительный контекст, поэтому доступ к странице ограничен администраторами. Payload по умолчанию отключён на уровне API; интерфейс не включает его сохранение.
