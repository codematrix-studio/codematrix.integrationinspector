# Дорожная карта

Обновляется по мере выполнения задач. Статусы отражают фактическое состояние, а не намерения.

| Этап | Результат | Статус |
|---|---|---|
| 0. Концепция | Назначение, аудитории, границы продукта | Выполнено предварительно |
| 1. Спецификация MVP | Функции, безопасность, критерии готовности | Черновик уточнён |
| 2. Архитектура | API, подсистемы, схема данных | Проект API подготовлен; схема данных не завершена |
| 3. Технические проверки | Матрица Битрикс/PHP/БД, требования Маркета | Первичная проверка PHP/MySQL выполнена; остальные проверки не завершены |
| 4. Прототип API | Контракт и тестовые сценарии | Проект контракта подготовлен; не утверждён |
| 5. Ядро | Жизненный цикл событий и безопасная запись | Не начато |
| 6. Хранилище | Таблицы, выборки, очистка | Не начато |
| 7. Административная панель | Журнал, фильтры, карточка события | Не начато |
| 8. Тестирование | Автотесты, ручные проверки, нагрузка | Не начато |
| 9. Релизная подготовка | Документация, упаковка, описание продукта | Не начато |

## Правило перехода между этапами

Этап не отмечается выполненным только потому, что он описан. Нужны проверяемые результаты: код, тесты, решение или подтверждённая проверка.

## Ближайшие задачи

1. Согласовать или скорректировать проект публичного API из [API.md](API.md).
2. Уточнить открытые вопросы API: формат ID, результат begin(), регистрацию источников и пользовательский Sanitizer.
3. Проверить минимальную версию ядра Битрикс, ORM, установщик, права, cron/agents и требования Marketplace.
4. Спроектировать физическую схему хранения с индексами и политикой роста данных.
5. После утверждения контрактов подготовить тестовые сценарии и только затем переходить к реализации.
