# CodeMatrix Integration Inspector

**Статус:** проектирование, MVP ещё не реализован.

CodeMatrix Integration Inspector — бесплатный распространяемый модуль для 1С-Битрикс, предназначенный для регистрации, просмотра и диагностики событий обмена данными между сайтом и внешними системами.

Проект создаётся CodeMatrix STUDIO как открытый инженерный продукт и публичная демонстрация качества разработки. Его стратегическая цель — приносить практическую пользу сообществу 1С-Битрикс-разработчиков, укреплять узнаваемость CodeMatrix STUDIO и подтверждать экспертизу автора реальным продуктом, кодом и документацией.

Модуль не реализует сами интеграции. Он предоставляет единый API и инструменты наблюдаемости, которые разработчики подключают к своим обработчикам обмена.

## Цели проекта

- Сократить время поиска причин сбоев интеграций.
- Предоставить единый журнал входящих и исходящих операций.
- Показывать технический контекст: источник, операцию, направление, длительность, результат и ошибку.
- Безопасно работать с чувствительными данными.
- Не вмешиваться в бизнес-логику подключённой интеграции.
- Дать сообществу полезный инструмент, который можно свободно получать и использовать на условиях выбранной лицензии.
- Демонстрировать качество архитектуры, PHP-разработки, тестирования и документации CodeMatrix STUDIO.

## Распространение

Продукт планируется распространять бесплатно. Платные редакции, подписки и ограничения функций ради монетизации не являются целью проекта.

Конкретная лицензия исходного кода ещё не выбрана. До её выбора нельзя считать условия повторного распространения, изменения и коммерческого использования юридически определёнными.

## Принципы

1. Безопасность журналируемых данных — обязательное требование.
2. Диагностический код не должен ломать основную интеграцию.
3. Никакого автоматического перехвата всех запросов без явного подключения.
4. Публичный API отделён от внутренней реализации.
5. Проект ориентирован на бесплатное распространение и пользу сообществу.
6. Решения и изменения фиксируются в документации и Git-истории.

## Совместимость

Целевая платформа — 1С-Битрикс: Управление сайтом. Предварительная цель для PHP — 8.2+, но точная матрица совместимости будет утверждена после проверки требований актуальных версий Битрикс и окружений.
