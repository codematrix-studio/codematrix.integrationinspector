## [Unreleased]

### Build and release
- Добавлен детерминированный сборщик штатного пакета Bitrix `scripts/build-update.sh`: проверяет версию и обязательные файлы, формирует ZIP с корневым updater.php и description.ru, проверяет целостность и структуру архива.
- GitHub Actions собирает пакет 0.1.1 и прикладывает ZIP как artifact на 14 дней. Публикация GitHub Release и сервера обновлений не автоматизирована.
- Документация установки и миграций синхронизирована с фактической сборкой; ручная проверка обновления на BitrixVM остаётся обязательной.

### Security and admin hardening
- Admin wrapper имеет маркер владения; установщик не перезаписывает чужой файл с тем же именем, а при удалении удаляет только принадлежащую модулю текущую или известную legacy-копию.
- Theme assets устанавливаются без перезаписи существующих файлов; при удалении сохраняются ресурсы, изменённые администратором или заменённые другим приложением.
- Откат неудачной установки удаляет только wrapper и theme assets, созданные именно этой попыткой; ранее существовавшие файлы остаются на месте.
- Повторная установка не перезаписывает уже принадлежащий модулю административный wrapper, включая известную legacy-версию.
- Updater проверяет наличие исходников миграций в пакете, результат `CopyFiles()` и SHA-256 скопированных файлов до запуска мигратора. Путь `curModulePath` разрешается относительно `DOCUMENT_ROOT` по контракту CUpdater.
- Проверка baseline схемы дополнительно сверяет типы индексов, префиксную длину и направление сортировки, а не только имена и состав колонок.
- Доступ к административной странице ограничен администраторами; вывод значений экранируется.
- GET-фильтры и пагинация нормализуются и ограничиваются.
