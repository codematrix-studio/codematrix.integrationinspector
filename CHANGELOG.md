## [Unreleased]

### Documentation
- Добавлен SCHEMA-MIGRATIONS.md: описаны отдельная версия схемы, baseline для существующей установки 0.1.0, повторяемость DDL, защита от параллельных запусков, fail-closed поведение и обязательные проверки. Это проект решения; код мигратора и интеграция с lifecycle Bitrix ещё не реализованы.
- INSTALLATION.md и ROADMAP.md синхронизированы с проектом миграций и явно отделяют спроектированную работу от реализованного кода.
- В TEST-PLAN.md добавлены сценарии baseline для версии 0.1.0, отказа на неполной схеме, повторного запуска после частичного DDL, параллельного запуска, неизвестной версии и вызова updater.php.

### Security and admin hardening
- Admin wrapper получил постоянный маркер владения: установщик обновляет принадлежащий модулю файл, не трогая чужой файл с таким же именем; удаление поддерживает маркер и legacy-копию.
- Установщик больше не перезаписывает существующий /bitrix/admin/cmi_integrationinspector_events.php с другим содержимым; при удалении удаляет только точную копию собственного wrapper. При сбое установки выполняется best-effort очистка собственных admin/theme-файлов, таблицы истории сохраняются.
- Доступ к административной странице после отказа ACL прекращается явным return; добавлен отдельный HtmlEscaper и unit-тесты для script/img, кавычек, некорректного UTF-8 и null.
- GET-параметры страницы нормализуются: массивы вместо строк игнорируются, номер страницы ограничен; фильтры репозитория также безопасно игнорируют массивы.
- Навигация журнала ограничена первой, последней и ближайшими к текущей страницами, чтобы не выводить сотни/тысячи ссылок.
- GitHub Actions после исправления namespace в HtmlEscaperTest: PHP syntax lint и PHPUnit успешно прошли на PHP 8.2, 8.3 и 8.4 (run 45362447811).

### Added
- Добавлен административный журнал событий: список с фильтрами по источнику, статусу, направлению, датам и Correlation ID, постраничный вывод и карточка события с дополнительными данными. Доступ ограничен администраторами; чтение выполняется через настроенное соединение Inspector.
- Добавлены EventRepository и unit-тесты проверки фильтров, экранирования SQL-значений и формата идентификатора события.
- Добавлен штатный файл admin/menu.php: пункт «Журнал интеграций» появляется в разделе «Сервисы» административной панели. Для пункта и страницы добавлены собственные SVG-иконки и CSS-тема, устанавливаемая в /local/themes/.default/ и очищаемая при удалении модуля.
- Установщик копирует только адресную административную точку входа в /bitrix/admin; файл меню остаётся в каталоге модуля. При удалении модуля удаляется только принадлежащая ему точка входа.
- Добавлена документация первой версии административного интерфейса и ссылка на страницу в README.

### Added
- Добавлена безопасная диагностика причин STORAGE_UNAVAILABLE: класс исключения и очищенное сообщение записываются в системный PHP error log; диагностический сбой не влияет на основную интеграцию. Добавлены unit-тесты форматирования и маскирования.

### Verified
- На BitrixVM проверена реальная независимая запись Inspector: событие через inspector_storage сохранилось со статусом success после rollback бизнес-транзакции на default connection. Оба соединения указывают на БД sitemanager, но являются отдельными соединениями. Окружение: CentOS Stream 9, PHP 8.2.30, MySQL 8.0.44; версия ядра Bitrix не зафиксирована.

### Added
- Добавлен опциональный выбор соединения хранилища через настройку модуля connection_name: пустое значение использует default connection, заданное имя разрешается через Bitrix ConnectionPool; при отказе именованного соединения нет скрытого fallback.
- Добавлены MySqlEventStorage на Bitrix D7 Connection и повторно запускаемый SchemaInstaller для b_cmi_event, b_cmi_event_data и b_cmi_source; транзакции вызывающего приложения не открываются и не завершаются.
- Добавлены install/index.php и install/version.php: первичная установка создаёт таблицы на default connection и регистрирует модуль после успешного DDL; обычное удаление снимает регистрацию, сохраняя историю. Публичные DTO/enum API, фасад Inspector::begin(), EventHandle, no-op и рабочий handle, EventService, контракт EventStorage, генератор UUID v4, Sanitizer и регистрация классов через Bitrix Loader.
- Добавлены unit-тесты EventService: проверка маскирования метаданных, выключенного по умолчанию payload, успешной и повторной финализации, маскирования токена, отключённой по умолчанию записи пути/строки исключения, отключённого сервиса и отказа хранилища.
- Контракт EventStorage возвращает явный FinalizeResult, чтобы различать повторную финализацию, отсутствие записи и недоступность хранилища.
- Путь и строка исключения выключены по умолчанию; сбор включается отдельной настройкой сервиса.
- Для события документировано отдельное поле OCCURRED_AT, не подменяющее системное DATE_START.
- Исправлено маскирование Authorization Bearer и объявление Throwable в NullEventHandle.
- GitHub Actions: Composer validate, установка зависимостей, PHP syntax lint и PHPUnit прошли на PHP 8.2, 8.3 и 8.4 для SQL-адаптера и SchemaInstaller.
- Добавлены Composer/PHPUnit dev-конфигурация, первые unit-тесты для входных данных, UUID, NullEventHandle и Sanitizer, а также GitHub Actions workflow для PHP 8.2–8.4.
