# История изменений

Все заметные изменения проекта фиксируются здесь. Даты указаны в формате YYYY-MM-DD.

## [Unreleased]

### Added
- Создана начальная документация концепции CodeMatrix Integration Inspector.
- Зафиксированы предварительные границы MVP.
- Добавлены архитектурное предложение, дорожная карта и журнал решений.
- Добавлен проект публичного API: фасад, EventHandle, жизненный цикл, корреляция, payload и политика отказов.
- Добавлен документ первичной проверки требований совместимости платформы.
- Добавлен корневой файл LICENSE со стандартным текстом MIT License.
- Добавлена ревизия публичного API с рекомендациями по no-op handle, источникам, идентификаторам, финализации и payload.
- API.md обновлён до версии 0.2: begin() всегда возвращает безопасный handle, справочник источников отделён от события, уточнены идентификаторы, финализация и правила payload.
- Добавлен проект физической модели хранения: таблицы событий, данных и источников, индексы, лимиты, retention и сценарии проверки ORM/транзакций.

### Changed
- Уточнена спецификация MVP с учётом контракта API.
- Архитектура дополнена разделом публичного API и ссылкой на совместимость.
- D-006 уточнено по официальным требованиям PHP 8.2 и MySQL 8.0; совместимость самого модуля не объявлена подтверждённой.
- Стратегия продукта закреплена: бесплатное распространение без платных редакций и подписок; основной эффект — польза сообществу и узнаваемость CodeMatrix STUDIO.
- README и PRODUCT.md отражают репутационную и общественную цель проекта.
- Выбрана MIT License (SPDX: MIT); README и PRODUCT.md содержат условия и ссылку на LICENSE.
- В ROADMAP добавлен предварительный календарный план на 8–10 недель с указанием допущений и контрольных результатов.
- В ROADMAP добавлен отдельный этап ревизии API; рекомендации пока не считаются утверждённым публичным контрактом.
