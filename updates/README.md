# Пакеты обновлений Bitrix

## 0.1.1

`updates/0.1.1/updater.php` — исходник `updater.php` для корня штатного пакета обновления Bitrix.

При сборке архива обновления необходимо:

1. Создать временный каталог пакета `0.1.1`.
2. Скопировать в его корень актуальное содержимое каталога модуля `local/modules/codematrix.integrationinspector/`, сохранив структуру `lib/`, `admin/`, `install/` и `include.php`.
3. Положить `updates/0.1.1/updater.php` в корень пакета как `updater.php`.
4. Положить `updates/0.1.1/description.ru` в корень пакета.
5. Положить файл `version.php` с версией `0.1.1` и датой выпуска в корень пакета.
6. Проверить состав архива: `updater.php` должен находиться в корне, а `lib/Storage/` — содержать актуальные файлы мигратора.
7. Упаковать содержимое каталога пакета в архив `0.1.1.zip` или `0.1.1.tar.gz`.

Bitrix запускает корневой `updater.php` до автоматического копирования остальных файлов обновления. Поэтому скрипт сначала явно копирует `lib/Storage/` через штатный `$updater->CopyFiles()`, затем загружает `MigrationRunner` из `/local/modules/`. После успешного выполнения мигратора Bitrix продолжает стандартное копирование остальных файлов пакета.

Скрипт не предполагает наличие нового API в установленной версии модуля и не выполняет миграции на пользовательском хите. В случае несовпадения существующей схемы обновление завершается ошибкой; таблицы и данные автоматически не пересоздаются.

**Важно:** этот каталог — исходник и инструкция сборки, а не готовый архив обновления. Полный архив и установка через сервер обновлений Bitrix требуют отдельной проверки на целевой BitrixVM.
